# Security

Please do not disclose security vulnerabilities through a public issue.

Use GitHub's **Report a vulnerability** route in this repository's Security
tab, or contact [HollyHR support](https://developers.hollyhr.com/support) if you
cannot access it. Include the affected SDK version, a minimal reproduction and
the impact you observed. Do not include real employee data, API keys, webhook
secrets or customer identifiers in a public issue.

HollyHR will acknowledge a complete report, investigate it and coordinate a
fix and disclosure where appropriate. Supported versions are the current npm
`latest` release and any newer prerelease explicitly identified in this
repository.
