# Contributing

Thanks for helping improve the HollyHR TypeScript SDK.

Before opening a pull request:

1. Open or link an issue that explains the developer problem.
2. Keep generated operation metadata aligned with `openapi/openapi.v1.yaml`.
3. Run `npm ci` and `npm run check`.
4. Add or update focused tests for behavioural changes.
5. Do not include API keys, employee data or private HollyHR application code.

Small documentation and example fixes are welcome. Public API contract changes
must first ship through HollyHR's versioned API process; this repository does
not independently define new server behaviour.

The HollyHR maintainers review issues and pull requests. Paul Gould is the
current accountable repository owner.
